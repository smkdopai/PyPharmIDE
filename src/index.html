Shortcuts & help

Asking for input

When your program calls input(), the box under Output turns orange. Type your answer and press Enter.

Stepping through code

Click beside a line number to set a breakpoint, then press Step through. Move forwards and backwards to watch each variable change.

Files

Everything in the Files panel sits next to your script. pd.read_csv("data.csv") reads an uploaded file; files your program saves appear there too. Every open tab is also saved there, so one tab can import another.

Plots

Matplotlib and seaborn charts appear in Output and the Plots tab. Click a plot to enlarge or save it.
